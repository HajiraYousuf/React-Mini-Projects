# ⚛️ React Mini Projects

A collection of ** practical React mini projects** built to strengthen my skills in React, JavaScript, state management, reusable components, and modern UI development.

Each project focuses on a specific concept or functionality while providing hands-on experience building interactive and responsive web applications.

## 🚀 Projects

| #  | Project                   | Description                                                          |
| -- | ------------------------- | -------------------------------------------------------------------- |
| 01 | 🧮 **Calculator**         | A calculator for performing basic arithmetic operations.             |
| 02 | 🔤 **Character Counter**  | Counts characters dynamically as the user types.                     |
| 03 | 👥 **Contact List**       | Displays and manages a collection of contacts.                       |
| 04 | 🔢 **Counter**            | A simple project for practicing React state management.              |
| 05 | 🎲 **Dice Roller**        | Generates random dice results through user interaction.              |
| 06 | 🕐 **Digital Clock**      | Displays the current time and updates in real time.                  |
| 07 | 🖼️ **Image Gallery**     | A responsive gallery for displaying and exploring images.            |
| 08 | 🔐 **Password Generator** | Generates random passwords based on selected options.                |
| 09 | ⭐ **Rating**              | An interactive rating component built with React state.              |
| 10 | 🔎 **Search & Filter**    | Searches and filters data dynamically based on user input.           |
| 11 | 🛒 **Shopping List**      | Allows users to add, search, and remove shopping items.              |
| 12 | ⏱️ **Stopwatch**          | A stopwatch with start, stop, and reset functionality.               |
| 13 | 🎨 **Theme Switcher**     | Allows users to switch between different interface themes.           |
| 14 | ✅ **Todo App**            | A task management application for adding and managing tasks.         |
| 15 | 🌤️ **Weather App**       | Displays weather information through a simple interactive interface. |

## ⚙️ Getting Started

Clone the repository:

```bash
git clone https://github.com/HajiraYousuf/React-Mini-Projects.git
```

Navigate to the project:

```bash
cd React-Mini-Projects
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
